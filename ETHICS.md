# ETHICS — Principios Éticos del Proyecto

Este proyecto se rige por principios éticos estrictos. Cualquier
contribución debe cumplirlos. Si no, será rechazada.

## 1. Solo fuentes públicas

- Todo el contenido proviene de fuentes públicas verificables.
- No se usan datos filtrados, accesos no autorizados ni información
  obtenida ilegalmente.
- No se publican datos que no estén ya en dominio público.

## 2. Cero doxxing

- **No** se publican nombres legales de personas no públicas.
- **No** se publican direcciones, teléfonos, correos privados, DNI,
  pasaportes, cuentas bancarias ni datos similares.
- **No** se publican fotos íntimas, datos médicos ni información sensible.
- **Sí** se publican alias, handles, Session IDs, correos usados para
  actividad criminal y otros IOCs, porque son necesarios para la defensa
  y la denuncia.

## 3. Cero malware

- **No** se distribuyen binarios, exploits funcionales, web shells,
  ransomware, stealers ni herramientas ofensivas.
- **Sí** se documentan TTPs, CVEs y nombres de herramientas, con
  propósito defensivo.

## 4. Atribución cuidadosa

- Se distingue entre:
  - **Hechos verificados** (confirmados por fuentes oficiales o múltiples
    fuentes independientes)
  - **Atribuciones presuntas** (basadas en OSINT, no confirmadas)
  - **Opiniones** (del autor o de terceros)
- **No** se acusa sin evidencia.
- **No** se confunde a imitadores con el núcleo real.
- **No** se señala a opositores como aliados ni viceversa.

## 5. Propósito defensivo

- El objetivo es **proteger, denunciar y educar**.
- **No** se facilita, promueve ni participa en actividades ilícitas.
- **No** se ataca a personas ni organizaciones.
- **No** se busca notoriedad personal a costa de las víctimas.

## 6. Respeto a la ley

- Se cumplen las leyes aplicables (RGPD, LOPDGDD, etc.).
- Se respetan los términos de servicio de las plataformas.
- Se colabora con las autoridades.

## 7. Mínima exposición

- Se publica solo lo necesario para el propósito defensivo.
- Se redactan datos personales en capturas de pantalla.
- Se evita amplificar contenido dañino (pornografía, violencia, etc.).

## 8. Transparencia

- Se citan las fuentes.
- Se reconoce la incertidumbre.
- Se corrigen errores públicamente.
- Se aceptan críticas constructivas.

## 9. No discriminación

- No se ataca a personas por su origen, etnia, religión, género,
  orientación sexual, nacionalidad ni discapacidad.
- Se describe la actividad criminal, no a las personas.

## 10. Colaboración

- Se colabora con autoridades, investigadores y defensores.
- Se comparte información bajo TLP:WHITE.
- Se ayuda a víctimas y organizaciones afectadas.

---

## Cómo reportar una violación ética

Si detectas una violación de estos principios en este repositorio:

1. Abre un **issue** con la etiqueta `ethics` o `correction`.
2. O consulta [SECURITY.md](SECURITY.md) para reporte privado.

Toda violación será investigada y corregida.

**Recuerda:** Este proyecto existe para proteger, no para atacar.
