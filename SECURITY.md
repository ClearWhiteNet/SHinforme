# SECURITY — Política de Seguridad y Reporte

## 1. Propósito

Este repositorio contiene inteligencia de amenazas de fuentes públicas.
No contiene malware, exploits ni datos personales. Sin embargo, si
detectas algo que debería ser retirado, corregido o reportado, usa esta
política.

## 2. Qué reportar

Reporta si encuentras:

- **Datos personales (PII)** que deberían estar redactados
- **Malware** o código malicioso por error
- **Credenciales** o secretos expuestos
- **Violaciones éticas** (ver [ETHICS.md](ETHICS.md))
- **Errores factuales** graves
- **Enlaces a contenido ilegal**
- **Vulnerabilidades** en el repositorio (por ejemplo, en scripts)

## 3. Cómo reportar

### Para temas sensibles (PII, malware, credenciales)

**No abras un issue público.** Contacta directamente:

- **Email:** SpectrumSecIt@proton.me

Incluye:

- Descripción del problema
- Ubicación exacta (archivo, línea, URL)
- Captura o evidencia si es posible
- Tu contacto para seguimiento

### Para temas no sensibles (errores, correcciones)

Abre un **issue** con la etiqueta `correction` o `security`.

## 4. Plazos

- **Acuse de recibo:** 48 horas
- **Evaluación inicial:** 5 días
- **Corrección:** depende de la gravedad (24h para PII/malware, 30 días
  para errores menores)

## 5. Qué NO hacer

- **No** publiques datos personales en issues.
- **No** subas malware, exploits ni datos filtrados.
- **No** acuses sin evidencia.
- **No** uses este repositorio para atacar a nadie.

## 6. Colaboración con autoridades

Si el reporte implica actividad criminal, el autor colaborará con las
autoridades competentes.

## 7. Alcance

Esta política aplica a:

- Contenido del repositorio (docs, reports, etc.)
- Issues y PRs
- Scripts y herramientas incluidas
- Comunicaciones del proyecto

## 8. Reconocimiento

Si reportas algo válido y quieres reconocimiento, se te mencionará en
[CHANGELOG.md](CHANGELOG.md) (salvo que prefieras anonimato).
