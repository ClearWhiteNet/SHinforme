# CONTRIBUTING — Cómo Contribuir

Gracias por tu interés en contribuir. Este proyecto tiene fines
**defensivos, educativos y de denuncia**. Lee [ETHICS.md](ETHICS.md)
antes de contribuir.

## 1. Qué aceptamos

- **Correcciones factuales** con fuentes verificables
- **Nuevos IOCs** de fuentes públicas
- **Traducciones** del informe
- **Mejoras de formato** o redacción
- **Nuevas fuentes** públicas relevantes
- **Análisis técnico** de TTPs documentadas

## 2. Qué NO aceptamos

- **Datos personales (PII)** de víctimas o personas no públicas
- **Malware, exploits funcionales** o herramientas ofensivas
- **Datos filtrados** o información obtenida ilegalmente
- **Acusaciones sin evidencia** o ataques ad hominem
- **Contenido ilegal** bajo cualquier jurisdicción
- **Spam, publicidad** o autopromoción
- **Doxxing** o acoso

## 3. Cómo contribuir

### Issues

- Usa la plantilla adecuada (`bug_report` o `correction`).
- Sé específico: archivo, línea, problema, fuente.
- No publiques PII en issues.

### Pull Requests

1. Haz fork del repositorio.
2. Crea una rama descriptiva (`fix/typo-informe`, `add/nuevo-ioc`).
3. Sigue el estilo del proyecto (Markdown, español).
4. Cita fuentes públicas.
5. Asegúrate de cumplir [ETHICS.md](ETHICS.md).
6. Abre el PR con la plantilla.
