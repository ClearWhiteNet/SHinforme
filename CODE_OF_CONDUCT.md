# CODE OF CONDUCT — Código de Conducta

## 1. Nuestro compromiso

Nos comprometemos a mantener un entorno **respetuoso, profesional y
ético** para todas las personas que participan en este proyecto,
independientemente de su edad, origen, etnia, religión, género,
orientación sexual, nacionalidad, discapacidad o nivel de experiencia.

## 2. Comportamiento esperado

- **Respeto:** trata a los demás con respeto.
- **Profesionalidad:** mantén un tono profesional.
- **Evidencia:** cita fuentes, no acuses sin prueba.
- **Ética:** cumple [ETHICS.md](ETHICS.md).
- **Colaboración:** ayuda a mejorar el proyecto.
- **Privacidad:** no publiques datos personales.
- **Legalidad:** cumple las leyes aplicables.

## 3. Comportamiento inaceptable

- **Acoso** de cualquier tipo.
- **Doxxing** o publicación de datos personales.
- **Ataques ad hominem** o insultos.
- **Discurso de odio** o discriminación.
- **Spam** o autopromoción.
- **Publicación de malware** o contenido ilegal.
- **Acusaciones sin evidencia.**
- **Suplantación** de identidad.
- **Interferencia** con el trabajo de otros.

## 4. Alcance

Este código aplica a:

- Issues y PRs
- Comentarios en el repositorio
- Comunicaciones del proyecto (email, Signal, etc.)
- Eventos relacionados

## 5. Aplicación

Las violaciones serán investigadas por el mantenedor. Las medidas
pueden incluir:

- Advertencia
- Eliminación de contenido
- Bloqueo temporal
- Expulsión permanente

## 6. Reporte

Reporta violaciones a:

- **Email:** SpectrumSecIt@proton.me
- **Privado:** ver [SECURITY.md](SECURITY.md)

Todas las quejas serán tratadas con confidencialidad.

## 7. Atribución

Este código se inspira en el [Contributor Covenant](https://www.contributor-covenant.org/),
adaptado a un proyecto de threat intelligence.

---

**Recuerda:** este proyecto existe para proteger, no para atacar.
